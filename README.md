---

## 1. Challenge Overview
The RevenueCat Shipaton is an intensive hackathon focused on shipping complete, commercially viable mobile and cross-platform apps to production. 

### Mandatory Eligibility Rule:
- Must integrate the **RevenueCat SDK** (`Purchases`) for in-app subscriptions, one-time purchases, or paywalls.
- Must demonstrate an active, polished user journey with real subscription or paywall triggers.

### Judging Criteria
1. **Product Execution & Polish (30%):** Delightful UI/UX, buttery smooth interactions, cohesive design system.
2. **Monetization Architecture (25%):** Smart, non-intrusive paywalls, dynamic pricing tiers, or high-conversion feature gating via RevenueCat.
3. **Utility & Value Proposition (25%):** High daily active usage potential, retention loops, solving a clear user pain point.
4. **Technical Architecture (20%):** Robust state management, offline-first resilience, and reliable subscription synchronization.

---

## 2. Selected Project Concept: HabitFlow Pro (Adaptive AI Habit & Flow Coach)
A cross-platform productivity and micro-journaling application built with React Native / Expo that integrates dynamic AI routine generation, Apple Health / Google Fit sync, and an adaptive RevenueCat paywall offering personalized subscription tiers.
